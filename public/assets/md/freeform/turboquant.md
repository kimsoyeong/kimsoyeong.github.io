# TurboQuant: 벡터 양자화의 새 기준

## Overview

TurboQuant는 두 개의 독립된 양자화기를 조합합니다.

- **Qmse**: 재구성 오차(MSE)를 최소화
- **Qprod**: MSE 양자화 후 잔차에 QJL 변환을 추가하여 내적 추정의 편향을 제거

## 핵심 아이디어

기존 양자화 방법들은 MSE 최적화에만 집중하지만, 내적(dot product) 연산에서의 편향 문제를 간과합니다. TurboQuant는 이 두 가지를 분리하여 각각 최적화합니다.

## 파이프라인

1. **랜덤 회전** — 입력 벡터에 랜덤 직교 행렬을 곱하여 Beta 분포를 유도
2. **스칼라 양자화** — Lloyd-Max 코드북으로 각 차원을 독립적으로 양자화
3. **잔차 추출** — 원본과 양자화된 벡터의 차이를 계산
4. **QJL 변환** — 잔차에 sign(S · r)을 적용하여 1-bit로 편향 제거

## 결론

TurboQuant는 이론적 하한선에 근접하는 성능을 보이며, KV Cache 양자화와 ANN 탐색에서 기존 방법 대비 우수한 결과를 달성합니다.
