>
> - LangChain은 Slack 대화마다 작업 환경을 유지하는 디자인 에이전트를 공개했다. 디자인 기준과 렌더 확인을 모델 밖의 작업 환경에 담았다.
> - Google Research는 대화 중 얻은 정보를 오프라인 학습으로 모델 가중치에 옮기는 sleep 프레임워크를 소개했다. 대화 기록을 저장하는 메모리와는 다르다.

## 1. 디자인 에이전트의 품질은 모델뿐 아니라 작업 환경에서 갈린다

- 무엇이 바뀜: LangChain은 Slack에서 영상, 그래픽, 슬라이드를 만드는 Content Studio의 구현과 오픈소스 저장소를 공개했다.
- 기존 대비 차이: 대화 스레드마다 독립된 작업 환경을 유지하고, 디자인 원칙과 피드백 이유를 제공한다. 에이전트가 렌더 결과를 확인하며 긴 작업은 비동기 하위 에이전트로 처리한다.
- 팀원은 같은 스레드에서 작업 방향을 바꿀 수 있고 결과물을 내보내기 전 승인한다. LangChain은 사내에서 3,000개 이상의 결과물을 만들었다고 밝혔다.
- **기술/산업 영향:** 해석: 디자인 에이전트 도입에서는 모델 교체만 비교하기보다, 작업 맥락 유지와 시각적 검토, 팀의 승인 절차를 함께 설계할 필요가 있다.
- **검증 행동:** 같은 디자인 요청에 브랜드 지침만 준 경우와 렌더 확인/피드백까지 제공한 경우를 비교한다.
- **한계:** 사내 사용 사례와 제작량은 LangChain의 설명이다. 일반 디자인팀에서도 같은 품질이나 시간 절감이 나온다는 독립 비교는 아니다.

## 2. LLM의 새 지식을 대화창 밖에 남기는 오프라인 학습

- 무엇이 바뀜: Google Research는 상호작용하는 단계와 학습에 집중하는 단계를 번갈아 실행하는 sleep 프레임워크를 소개했다.
- 기존 대비 차이: 대화 중 임시로 보관한 정보를 새 메모리 블록의 가중치에 학습시킨다. 대화창에 정보를 계속 넣는 방식과 달리 모델의 파라미터 자체를 갱신한다.
- 연구진은 새 사실 습득과 최대 1,000만 토큰의 긴 맥락 지식 보존, 추론 개선을 보고했다. 이 수치는 연구진이 정한 실험 조건의 결과다.
- **기술/산업 영향:** 해석: 장기 기억을 구현할 때 저장된 문서를 찾아 넣는 방식과 모델을 다시 학습시키는 방식은 운영 비용과 검증 대상이 다르다. 기억 기능이라는 이름만으로 같은 기술로 보면 안 된다.
- **검증 행동:** 장기 기억 기능을 비교할 때 외부 기록 저장인지, 가중치 갱신인지 먼저 구분하고 이전 지식 성능도 함께 평가한다.
- **한계:** 스스로 구조나 코드를 바꾸는 시스템이 아니다. 고정된 모델 구조와 사람이 정한 학습 규칙 안에서 동작하며, 추가 학습에는 별도의 계산이 필요하다.

## 3. AI에게 연구의 참신함을 채점시키기 전에 질문부터 검증해야 한다

- 무엇이 바뀜: Ai2는 연구 아이디어의 참신함을 평가하는 6개 LLM을 비교한 연구와 평가 데이터, 코드를 공개했다.
- 기존 대비 차이: 같은 아이디어를 비교하면서 질문의 몇 단어만 바꿨는데도 한 모델의 정확도가 50%p 넘게 달라졌다. 추가 검색과 추론도 일관된 개선을 만들지 못했다.
- 평가 자료는 ICLR 2026 논문 심사에서 참신함을 칭찬받은 아이디어와 지적받은 아이디어를 추출해 구성했다. 논문 채택 여부 자체를 참신함의 정답으로 쓰지는 않았다.
- **기술/산업 영향:** 해석: 연구 아이디어를 생성하는 에이전트와 채점하는 에이전트를 연결해도 검증이 끝나는 것은 아니다. 채점 질문에 따라 후보 순위가 바뀌는지 별도로 확인해야 한다.
- **검증 행동:** 아이디어 후보를 고정한 뒤 질문 표현을 바꿔 채점하고, 순위가 뒤집힌 후보는 사람이 원문 근거를 확인한다.
- **한계:** 심사 의견을 바탕으로 만든 평가 기준이므로 연구의 참신함을 완벽히 측정하는 정답은 아니다. 보고된 민감도를 모든 모델과 모든 연구 분야에 일반화할 수 없다.
